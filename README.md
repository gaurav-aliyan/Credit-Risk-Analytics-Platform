# Credit Risk Analytics Platform

## 📌 Overview

This project demonstrates an end-to-end Credit Risk Analytics Platform built using SQL, Python, Machine Learning, and Power BI.

The objective is to predict customer default risk, generate credit risk scores, estimate expected loss, and support data-driven loan approval decisions.

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- SQL
- Scikit-learn
- Power BI
- Git & GitHub
